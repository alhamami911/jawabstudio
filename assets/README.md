# الأصول (Assets)

- `logo/`   : شعار Jawab.
  - `jawab logo.png` و`pp.png`: الأصلان المُقدَّمان (خلفية شفافة).
  - `logo.trim.png`: نسخة مقصوصة الهوامش بعرض 800px، وهي التي يستخدمها المسجّل في بطاقتي العنوان والختام وفي شريط الشرح.
    لإعادة توليدها من شعار جديد: قصّ الهوامش الشفافة وحوّله إلى `logo.trim.png` بعرض نحو 800px.
- `music/`  : موسيقى الخلفية. ضع هنا أي ملف (mp3/wav/m4a/ogg) وسيُستخدم تلقائيًا عند `npm run mp4`، وله الأولوية على المولَّد.
  - `ambient-generated.mp3`: مقطع هادئ مولَّد بالتركيب الصوتي (`npm run music:gen`)، خالٍ من حقوق النشر، وهو بديل مؤقت.
  - تجنّب ملفات الموسيقى التي لا تملك ترخيص استخدامها في فيديوهات منشورة.
  - لتعطيل الموسيقى: `npm run mp4 -- <id> --no-music`.
- `images/` : الصور والخلفيات واللقطات المساعدة.
- `fonts/`  : الخطوط (للعناوين والترجمة النصية).

ألوان الهوية (من الشعار): كحلي `#1e3a8a`، أزرق فاتح `#60a5fa`، أخضر `#10b981`.

## مقدمة وخاتمة وأغلفة المسؤول (تُدمج تلقائيًا)
- `intro/` و`outro/`: ضع ملف mp4 باسم `16x9.mp4` (للأفقي) و`vertical.mp4` (للعمودي). أو ملفًا واحدًا بأي اسم يُلائَم لكلا النسبتين (تحجيم وحشو أبيض). الصوت اختياري.
- `covers/<السلسلة>.png|jpg`: مثل `accounting-basics.png` (1280×720). تُنسخ بجانب كل فيديو باسم `cover.png`.
- يلصقها `scripts/wrap-assets.mjs` عند آخر مرحلة `process`/`vprocess`. لا ملفات = لا تغيير. لتعطيلها لحلقة: `node scripts/to-mp4.mjs <id> --no-wrap`.
