# Jawab Tutorial Builder (Jawab Studio)

> للمطوّرين: ابدأ من [CONTRIBUTING.md](CONTRIBUTING.md) (الإعداد، هيكل المستودع، قواعد الأمان). المتغيرات في `.env.example`.

يسجّل فيديوهات تعليمية لنظام Jawab ERP من سيناريو JSON: تسجيل شاشة، شرح مكتوب، تكبير عند النقر والكتابة، تعليق صوتي عربي، موسيقى خلفية، وبطاقتا عنوان وختام بهوية Jawab.

## إنشاء حلقة
1. انسخ `scenarios/_template.json` إلى `scenarios/<id>.json` وعدّل `id` والعنوان والخطوات.
2. `npm run record -- scenarios/<id>.json` ← ينتج `output/<id>/raw.webm` و`events.json` و`steps.md` وصوتًا في `audio/`.
3. `npm run mp4 -- <id>` ← ينتج `output/<id>/<id>.mp4` (فيديو + تعليق + موسيقى).

## أنواع الخطوات
| action | الحقول | ملاحظات |
|---|---|---|
| `goto` | `url` | |
| `click` | `selector` | تكبير تلقائي |
| `fill` | `selector`, `value` | `${VAR}` من `vars` أو `.env`؛ تكبير تلقائي |
| `select` | `selector`, `label` | قائمة `<select>` بالنص الظاهر؛ تكبير تلقائي |
| `hide` | `selector` | إخفاء عنصر مزعج |
| `wait` | `ms` | |

لكل خطوة اختياريًا: `narration` (الشريط المكتوب)، `speech` (النص المنطوق إن اختلف)، `zoom` (رقم أو `false`، الافتراضي 1.6).

حقول السيناريو: `login` (دخول في الخلفية لا يظهر في الفيديو)، `start`، `hide`، `intro`/`outro`، `vars`.
`vars` يحسب قبل التسجيل أول قيمة غير مستخدمة في النظام (مثل كود حساب فريد):
`"vars": { "CODE": { "model": "account.account", "field": "code", "start": 101200 } }` ثم `"value": "${CODE}"`.

## الصوت والموسيقى
- `.env`: `ELEVENLABS_API_KEY` و`ELEVENLABS_VOICE_ID` (والنموذج اختياري `ELEVENLABS_MODEL`). ElevenLabs هو مزوّد الصوت الوحيد.
- الجمل تُخزَّن مؤقتًا في `output/<id>/audio/`، فتعديل جملة يعيد توليدها هي فقط.
- `--no-voice` في `record`، و`--no-music` أو `--music <ملف>` في `mp4`.
- `npm run voices` أصوات ElevenLabs، و`npm run voice:design` ينشئ صوتًا جديدًا من وصف، و`npm run music:gen` يولّد موسيقى بديلة.
- موسيقاك الخاصة: ضعها في `assets/music/` ولها الأولوية.

## تنبيهات
- كل تسجيل ينفّذ الخطوات فعليًا على النظام (ينشئ بيانات). استخدم بيئة تجريبية.
- `scripts/ops/delete-account.mjs <code>` يحذف حسابًا من شجرة الحسابات.
- الهوية في `assets/logo/` (الشعار المقصوص `logo.trim.png`) وألوانها في `src/overlay.ts`.

# الإنتاج التلقائي لسلاسل كاملة (الطابور)

```
npm run queue -- plan:check                  فحص كل الخطط (سلامة + وجود القوائم فعلًا في Jawab)
npm run queue -- add accounting-basics       إضافة كل حلقات السلسلة إلى الطابور (أو --eps 1-5,8)
npm run queue -- start                       تشغيل العامل في الخلفية (يستمر بعد إغلاق VS Code وClaude)
npm run dashboard                            لوحة المتابعة: http://127.0.0.1:4173
npm run queue -- status
npm run queue -- pause|resume|cancel|retry <series|jobId>
npm run queue -- pause-all | resume-all
npm run dryrun -- accounting-basics 3,7      تجربة بلا صوت (لا تصرف رصيد ElevenLabs) لكشف الخطوات المكسورة
npm run discover                             حفظ قوائم Jawab الفعلية في catalog/menus.json
```

- **الحالة** في `data/queue.json` (نسخة احتياطية `.bak`). عامل واحد فقط ينفّذ، فلا تتعارض حلقتان على جلسة Jawab نفسها.
- **الاستئناف:** عند إعادة تشغيل العامل تعود الحلقات المقطوعة إلى الطابور من آخر مرحلة أُنجزت (prepare ← record ← process ← validate ← publish). المحاولة المقطوعة لا تُحتسب.
- **الإعادة:** لكل مرحلة حد محاولات في `config/production.json`. الحلقة الفاشلة تنتظر ثم تعود للطابور بينما تُنتج الحلقات الأخرى؛ بعد استنفاد المحاولات تصبح Failed دون أن توقف غيرها.
- **الاعتماد:** حلقة لها `dependsOn` تنتظر اكتمال ما تعتمد عليه، وتُتخطى (Skipped) إن فشل.
- **تعطل مزود الصوت** (مفتاح خاطئ/نفاد الرصيد) يوقف الطابور كله مؤقتًا بدل إفشال كل الحلقات؛ أصلح ثم `resume-all`.
- **بعد إعادة تشغيل الجهاز:** شغّل `npm run queue -- start` مرة أخرى، فالطابور محفوظ.

## المكتبة
`library/<series>/ep-NN/vK/`: `episode.mp4`، `metadata.json`، `scenario.json`، `narration.md`، `steps.md`، `validation.json`، `production.log`. `library/index.json` يفهرس كل النسخ. إعادة التوليد (`add --regenerate` أو زر «إعادة توليد») تنتج `v+1` ولا تمس القديم.

## التحقق الآلي من الجودة (`src/queue/validate.ts`)
الخطوات نُفّذت كلها؛ النتيجة تحققت فعلًا في النظام (سجل أُنشئ / عنصر ظاهر)؛ الفيديو يُفكّ بلا أخطاء ومساراه موجودان؛ التعليق موجود ومتزامن مع خطواته ومسموع؛ لا شاشة سوداء أو بيضاء فارغة؛ لا جمود طويل بلا كلام؛ لا صمت طويل؛ العنوان والترقيم متطابقان. عند الفشل تُعاد المرحلة المتأثرة فقط (التصدير وحده، أو التسجيل ثم التصدير).
ملاحظة صريحة: «الأهداف» تُربط بنتيجة متحقَّق منها بنيويًا؛ لا يوجد حكم آلي على جودة الشرح نفسه، ولا قراءة للنص المرسوم على الشاشة.

## التأليف
`series/<id>/series.json` و`series/<id>/NN-slug.json`. خطوات مختصرة: `app`, `nav`, `new`, `field` (`kind`: char/select/m2o), `save`, `search`, `look`، أو خطوات المسجّل الخام. أمثلة في `series/accounting-basics/`. كل حلقة يجب أن تعرّف أهدافها ونتيجتها المتوقعة و`verify`، وإلا رُفضت قبل التسجيل.
`scripts/probes/probe-form.mjs <actionId>` يعرض حقول نموذج «جديد» الحقيقية؛ `npm run discover -- <model>` يحفظ حقول نموذج.

## الأمان
- لا يعمل إلا على المضيف المذكور في `allowedHosts` (`config/production.json`).
- ترفض الخطة خطوة تبدو هدّامة (حذف/أرشفة/إلغاء/عكس…) وأي كتابة بلا إنشاء سجل جديد (إلا `allowEdit`).
- الحلقات تنشئ سجلات اختبار جديدة فقط وتحفظ أرقامها في `metadata.json` (`createdRecords`). الفواتير تبقى مسودات ولا تُرحَّل. لا حذف تلقائي لبيانات الاختبار.
- لم تُدرَج حلقة «خطة تحليلية» لأن إنشاءها يغيّر بنية قاعدة البيانات نفسها.

## الحركات (`src/overlay.ts`)
مقدمة وختام متحركان بهوية Jawab، شريط شرح منزلق مع خط تقدم بطول مقطع الصوت، إطار تمييز نابض، مؤشر ينزلق إلى العنصر وموجة عند النقر، انتقال ناعم بين الشاشات والقوائم، وتلاشٍ في نهاية الفيديو (`--no-fx` في `mp4` لتعطيله). الحركة تُشغَّل من لحظة بدء مقطع الصوت.

# النسخة العمودية (شورتس / ريلز / تيك توك) وتنظيف بيانات الاختبار

- كل حلقة تُسجَّل مرتين تلقائيًا: أفقية 1280x720، وعمودية أصلية (نافذة 900x1600 ثم تصدير 1080x1920). العمودية شاشة واحدة متصلة بلا تقسيم؛ الشرح والمؤشر أكبر والشريط مرفوع فوق منطقة واجهة المنصات. تُحفظ في المكتبة باسم `reel.mp4` مع `thumbnail-vertical.png`.
- تنبيه: التسجيل العمودي ينفّذ الخطوات في Jawab مرة ثانية، فتُنشأ سجلات اختبار إضافية (بأرقام وأسماء تالية تلقائيًا). الصوت نفسه (يُنسخ من ذاكرة الصوت فلا يُصرف رصيد جديد).
- لا يوجد عدّاد "حلقة n من N" في أي مكان: كل حلقة تُنشر مستقلة.
- مقدمة الحلقة حيّة: أهداف التعلّم بعلامات صح يلمع كل منها بدوره، تقريب بطيء، خلفية تتحرك، وخط تقدم، وتحميل مسبق للتطبيق خلف البطاقة.
- **تنظيف بيانات الاختبار:** `npm run cleanup:test` يعرض (بلا حذف) ما أنشأته الحلقات، و`npm run cleanup:test -- --apply` يحذفه. يقتصر على سجلات أنشأها مستخدم الدروس نفسه بعد تاريخ `--since` (الافتراضي 2026-10-26) وبأسماء الحلقات فقط، ويعمل على المضيف المسموح فقط.
