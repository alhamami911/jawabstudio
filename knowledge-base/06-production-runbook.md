# 06 | دليل التشغيل

> على ويندوز: النودات ليست في PATH داخل PowerShell. نفّذ أولًا: `$env:Path += ';C:\Program Files\nodejs'` ثم استعمل `npm run ...` من مجلد المشروع. (في Git Bash: `export PATH="$PATH:/c/Program Files/nodejs"`.)

## الأوامر اليومية

| الغرض | الأمر |
|---|---|
| فحص كل الخطط والقوائم | `npm run queue -- plan:check` |
| تجربة حلقات بلا صوت وبلا تصدير (تنشئ سجلات اختبار في الشركة التجريبية) | `npm run dryrun -- accounting-basics 1-5` |
| إضافة حلقات للطابور | `npm run queue -- add accounting-basics --eps 1-5` |
| إعادة إنتاج حلقة (إصدار جديد) | `npm run queue -- add accounting-basics --eps 3 --regenerate` |
| حالة الطابور | `npm run queue -- status` |
| إيقاف/استئناف كل الطابور | `npm run queue -- pause-all` · `resume-all` |
| إيقاف/إلغاء/إعادة حلقة أو سلسلة | `npm run queue -- pause\|cancel\|retry <id>` |
| تشغيل العامل | `node node_modules/tsx/dist/cli.mjs src/cli.ts start` |
| لوحة المتابعة | `npm run dashboard` ثم http://127.0.0.1:4173 |
| ملء الديمو | `npm run seed:demo` |
| تحديث القاموس | `node scripts/kb/export-menu-translations.mjs && node scripts/kb/export-selection-translations.mjs && npm run kb` |
| اختبار نطق الصوت | `node scripts/voice/voice-ab.mjs "<مجلد>"` |
| لغة حساب الدروس | `node scripts/ops/set-lesson-lang.mjs ar_001\|en_US` |

- **الأفضل تشغيل العامل كمهمة خلفية مُدارة** وقراءة `data/worker.log` و`npm run queue -- status`. العمليات المفصولة (detached) تُقتل في بعض البيئات.
- الحلقة الواحدة بنسختيها تستغرق نحو 3–4 دقائق. دفعة من 5 حلقات: 18–20 دقيقة.

## التحقق الآلي (نحو 30 فحصًا لكل نسخة)
`files` · `workflow-executed` · `outcome-verified` (يتحقق عبر RPC أن السجل أُنشئ فعلًا) · `playable` · `streams` (الأبعاد) · `frame-filled` · `first-frame` · `narration-present` · `narration-synced` · `audible` · `no-long-silence` (أطول صمت 12 ثانية) · `no-black-screen` · `no-blank-white` · `no-unexplained-freeze` · `title-and-number` · `objectives-covered`.
الفشل يعيد المرحلة المسؤولة تلقائيًا (3 محاولات للتسجيل، مع تأخير 10 و30 و90 ثانية). بعد استنفاد المحاولات تُوسَم الحلقة «فشلت» وتُتخطى المعتمدة عليها.

## الفحص المسبق (prepare) يرفض الحلقة إن
- لا أهداف تعلّم أو لا نتيجة متوقعة أو لا فحوص تحقق (`verify`).
- خطوة تحوي كلمة حذف/أرشفة/إلغاء/عكس/إعادة تعيين.
- كتابة في حقول دون إنشاء سجل (إلا مع `allowEdit`).
- ترحيل أو تأكيد أو تحقق دون `allowPost`.
- فتح قائمة الشركات.
- عنوان مطلق لموقع آخر.

## قائمة مراجعة الجودة (بشرية، قبل التسليم)
الأرقام وحدها لا تكفي. **استخرج اللقطات وانظر إليها.**
1. **اللقطة الأولى (الثانية 0)** وأول 3 ثوانٍ: لا رمادي ولا ركن فارغ.
2. **شرائح المقدمة:** الخط، توازن الأسطر، تبدّل الشرائح مع الجمل.
3. **كل نقرة:** الإطار على العنصر الصحيح، ولا مربع أبيض بعدها.
4. **تطابق الشرح مع الشاشة:** المصطلحات حرفيًا.
5. **العمودي:** الشريط فوق الحافة بـ170 بكسلًا، لا فراغ كبير، لا قصّ.
6. **الاستماع:** الإلقاء متصل بلا تقطيع، النطق سليم، الموسيقى لا تطغى.
7. **أسماء حقيقية:** لا اسم عميل في أي لقطة.
8. **الخاتمة:** خلاصة ثم شكر ثم تشويق.
أمثلة أدوات الفحص: `ffmpeg -ss <ثانية> -i episode.mp4 -frames:v 1 -update 1 لقطة.png`.

## الأعطال المعروفة (وما تفعله)

| العَرَض | السبب | العلاج |
|---|---|---|
| «longest silent gap … intro → step 1» | تحميل JAWAB بطيء بعد المقدمة | يُعاد تلقائيًا؛ إن تكرر فشل فحص الاتصال |
| لقطة أولى رمادية في المشغّل | أول إطار في تسجيل Playwright ناقص | يُستبدل آليًا (`to-mp4.mjs`)، والفحص `first-frame` يراقبه |
| مربع أبيض بعد النقر | الإطار بقي والعنصر اختفى | يخفت لحظة النقر (تم الإصلاح) |
| قائمة منسدلة تتحرك عند التكبير | إعادة تموضع أثناء الـ zoom | `zoom:false` على نقرات القوائم |
| حقل m2o لا يختار | حدث `resize` يغلق الاقتراحات | انتظار 1.3 ثانية ثم أول عنصر، بلا تكبير |
| الدخول يفشل بمهلة | بطء الخادم مؤقت | أعد التشغيل |
| فشل البحث بالعربية | أسماء الحسابات عربية في الواجهة العربية | ابحث بالكود الرقمي (`101`) لا بالاسم |
| الواجهة بالعربية أو الإنجليزية خطأً | مفتاح اللغة يحفظ اللغة على الحساب | `scripts/ops/set-lesson-lang.mjs` |
| تحقق «Duration/streams» فاشل | تسجيل 1080p بـ deviceScaleFactor يكسر الإطار | ابقَ على 720p؛ العمودي أصلي 900×1600 |

## الأمان التشغيلي
- المضيف المسموح الوحيد: `samar.jawab.pro` (`config/production.json`).
- لا تحذف دفعة ملفات أو بيانات دون موافقة صريحة في كل مرة. (حذف الفيديوهات القديمة: `scripts/ops/clean-old-videos.mjs`، عرض فقط ثم `--apply`.)
- لا رفع إلى GitHub دون إذن.
- كلمات السر ومفاتيح ElevenLabs في `.env` فقط (مستبعد من Git)، ولا تُكتب في وثائق أو رسائل.
