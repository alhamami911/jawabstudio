# 01 | نظرة عامة

## ما هذا الاستديو
مصنع فيديوهات شرح لنظام JAWAB ERP (نسخة Odoo 18 على `samar.jawab.pro`). يسجّل شاشة النظام الحقيقية بواسطة Playwright، ويضيف تعليقًا صوتيًا عربيًا (ElevenLabs) وشريط شرح وإطارًا مضيئًا ومقدمة وخاتمة وموسيقى خلفية، ثم يصدّر **نسختين من كل حلقة**: أفقية 16:9 وعمودية 9:16 (Shorts وTikTok)، ويتحقق آليًا من الجودة.

المشروع: https://github.com/alhamami911/jawabstudio (TypeScript وNode وffmpeg).

## خط الإنتاج (المراحل)

| المرحلة | ماذا تفعل |
|---|---|
| prepare | فحص الإعدادات والمضيف المسموح والـ ffmpeg وفحص الحلقة مسبقًا (lint) |
| record | تسجيل الحلقة الأفقية مع الصوت |
| process | تصدير mp4 (موسيقى وتدرّج ختامي) |
| vrecord | تسجيل ثانٍ بنافذة عمودية 900×1600 |
| vprocess | تصدير الفيديو العمودي 1080×1920 |
| validate | نحو 30 فحصًا آليًا للنسختين |
| publish | نسخ الملفات إلى `library/` مع الترجمة والصور المصغّرة والبيانات |

كل مرحلة لها محاولات وإعادة تلقائية. الفشل في حلقة لا يوقف غيرها، والطابور يستأنف بعد أي انقطاع.

## مكونات الكود (للمطوّر)

| المسار | الدور |
|---|---|
| `series/<سلسلة>/` | `series.json` وملف JSON لكل حلقة (الخطوات والشرح والأهداف والتحقق) |
| `src/queue/plan.ts` | تحويل الحلقة إلى سيناريو، والفحص المسبق، ومطابقة القوائم بالعربية والإنجليزية |
| `src/record.ts` | المسجّل: المؤشر والتكبير والإطار والشريط وشرائح المقدمة |
| `src/overlay.ts` | كل ما يُرسم فوق الصفحة (شريط الشرح، الإطار، المقدمة والختام) |
| `src/tts.ts` | الصوت: الذاكرة المشتركة، إعدادات الإلقاء، ضغط الوقفات |
| `src/queue/worker.ts` | العامل: المراحل والإعادة والتعافي |
| `src/queue/validate.ts` | فحوص الجودة الآلية |
| `src/dashboard.ts` | لوحة المتابعة (المنفذ 4173) |
| `scripts/` | أدوات: `to-mp4`، البيانات التجريبية، التنظيف، القاموس، اختبار الصوت |
| `catalog/` | فهرس قوائم النظام وترجماتها (من النظام نفسه) |
| `config/production.json` | المضيف المسموح، المحاولات، المهل، حدود التحقق |

## المخرجات والمجلدات

| المجلد | محتواه |
|---|---|
| `output/<id>/` | عمل التسجيل المؤقت (فيديو خام، أحداث، صوت) |
| `library/<سلسلة>/ep-NN/vN/` | **الناتج النهائي**: `episode.mp4` (أفقي)، `reel.mp4` (عمودي)، `captions.srt`، `narration.md`، `thumbnail.png`، `thumbnail-vertical.png`، `metadata.json`، `validation.json`، `audio/` |
| `cache/tts/` | مقاطع ElevenLabs الخام المشتركة بين الإصدارات (لا تُحذف إلا عند الضرورة) |
| `data/` | حالة الطابور وسجلاته (لا تُحذف) |
| `assets/` | الشعار والموسيقى وعينات الصوت (`assets/voice/`) |
| `knowledge-base/` | هذه الوثائق |
| سطح المكتب | نسخ للمراجعة فقط، ليست مصدرًا |

اسم الإصدار `vN` يزداد مع كل إعادة إنتاج. الأحدث هو المعتمد ما لم يُقل غير ذلك.
