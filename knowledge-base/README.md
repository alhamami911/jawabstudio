## قواعد ذهبية (ملخص)

1. **لا نُظهر ولا نلمس بيانات العملاء الحقيقيين.** كل التسجيل في «شركة جواب التجريبية» فقط.
2. **الشاشة هي المرجع:** أي مصطلح بين « » في الشرح يطابق الشاشة العربية حرفيًا.
3. **JAWAB تُكتب بحروف لاتينية كبيرة ولا تُترجم**، وتُنطق «جواب».
4. **لا نشر علني دون موافقة بشرية.**
5. **لا حذف جماعي ولا رفع إلى GitHub دون إذن صريح في كل مرة.**
